# An-lisis-de-la-evoluci-n-hist-rica-del-precio-del-d-lar-en-Rep-blica-Dominicana-1985-2021-
Este proyecto analiza la evolución histórica del tipo de cambio entre el dólar estadounidense (USD) y el peso dominicano (DOP) utilizando información oficial del Banco Central de la República Dominicana.

El análisis combina técnicas de estadística descriptiva, análisis financiero, evaluación de volatilidad, análisis de spread cambiario y modelado predictivo para comprender la dinámica del mercado cambiario dominicano durante más de tres décadas.

# Objetivo

Evaluar la evolución histórica del dólar en República Dominicana e identificar patrones relevantes para la gestión financiera, el análisis de riesgo cambiario y la construcción de escenarios futuros.

# Principales hallazgos

✅ Depreciación acumulada superior al 1,600%.

✅ CAGR cercano al 8% anual.

✅ Identificación de una ruptura estructural durante la crisis bancaria del 2003.

✅ Volatilidad superior al 30% durante los años de mayor inestabilidad financiera.

✅ Reducción sostenida de la volatilidad después de 2005.

✅ Spread promedio de apenas 0.41%.

✅ Correlación prácticamente perfecta entre las tasas de compra y venta.
